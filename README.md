# BLACKFORGE — премиальный интернет-магазин дисков (PHP MVC)

Полноценный учебный проект интернет-магазина автомобильных дисков с пользовательской частью и админ-панелью.

## Реализованный функционал

### Пользовательская часть
- Главная: премиальный баннер, блок популярных и новых моделей, фильтр по авто, преимущества.
- Каталог: расширенная фильтрация (диаметр, PCD, ширина, ET, производитель, материал/тип, цвет, цена, наличие) и сортировка.
- Карточка товара: галерея (zoom через открытие изображения), характеристики, отзывы+рейтинг, рекомендованные товары, сравнение.
- Корзина: изменение количества/удаление (через 0), подсчет суммы, промокод, оформление заказа.
- Оформление: гость или авторизованный пользователь, имя/email/телефон/адрес, доставка, оплата, подтверждение.
- Личный кабинет: история и статусы заказов, повтор заказа, избранное, редактирование профиля, смена пароля.
- Регистрация/авторизация: CAPTCHA, CSRF, XSS-экранирование, prepared statements, восстановление пароля (демо), подтверждение email (демо).
- Дополнительно: сравнение товаров, отзывы (модерация как демо-процесс), онлайн-чат, подписка на новости, уведомление о поступлении.

### Админ-панель
- Доступ по ролям: Super Admin / Manager.
- Товары: базовый CRUD (создание + список), управление ценой/наличием, URL изображений.
- Заказы: список, статусы, просмотр и печать накладной (демо).
- Пользователи: список, заготовки для блокировки/смены роли.
- Аналитика: выручка, количество заказов, популярные товары, демо-метрики.
- SEO/контент: sitemap, ЧПУ, мета-теги, статические страницы (О нас, Доставка, Гарантия, Политика).
- Логирование: подготовлена инфраструктура `storage/logs`.

## Запуск
1. Скопируйте `config/config.example.php` в `config/config.php` и заполните параметры.
   - Если запуск из подпапки XAMPP (`http://localhost/blackforge`) — укажите `app.base_path = '/blackforge'`.
2. Импортируйте `database/schema.sql` и затем `database/seed.sql` в MySQL.
3. Запустите сервер:
   ```bash
   php -S 0.0.0.0:8080 -t public
   ```
4. Откройте `http://localhost:8080`.

### Запуск в XAMPP
1. Положите проект в `htdocs/blackforge`.
2. Откройте `http://localhost/blackforge/`.
3. Убедитесь, что включены `mod_rewrite` и `AllowOverride All`.

## Структура
- `app/Core` — ядро MVC и безопасность.
- `app/Controllers` — пользовательские/админ-контроллеры.
- `app/Models` — работа с БД.
- `app/Views` — шаблоны.
- `routes/web.php` — маршрутизация.
- `database/schema.sql` — нормализованная схема.
- `database/seed.sql` — начальное наполнение.
