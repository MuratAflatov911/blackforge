# BLACKFORGE — учебный интернет-магазин дисков

Минималистичный MVC-проект на чистом PHP 8.2+ и MySQL для учебной практики.

## Возможности
- Каталог с фильтрацией и сортировкой.
- Карточка товара с галереей и характеристиками.
- Корзина, избранное, промокоды, оформление заказа.
- Регистрация/вход, подтверждение email (заглушка), CAPTCHA (математическая), личный кабинет.
- Админ-панель: товары, заказы, пользователи, статистика.
- Безопасность: PDO prepared statements, CSRF, экранирование вывода, базовая валидация.
- SEO: ЧПУ-маршруты, мета-теги, sitemap.xml, lazy loading изображений.

## Запуск
1. Скопируйте `config/config.example.php` в `config/config.php` и заполните параметры.
   - Если проект запускается из подпапки XAMPP (`http://localhost/blackforge`), задайте `app.base_path = '/blackforge'`.
2. Импортируйте `database/schema.sql` в MySQL.
3. Запустите локальный сервер:
   ```bash
   php -S 0.0.0.0:8080 -t public
   ```
4. Откройте `http://localhost:8080`.


### Запуск в XAMPP (Windows)
1. Поместите проект в `htdocs/blackforge`.
2. В браузере открывайте `http://localhost/blackforge/` (корневой `index.php` перенаправит на front controller).
3. Убедитесь, что в Apache включен `mod_rewrite` и разрешен `.htaccess` (`AllowOverride All`).

## Структура
- `app/Core` — ядро MVC и безопасность.
- `app/Controllers` — пользовательские и админ-контроллеры.
- `app/Models` — доступ к данным.
- `app/Views` — шаблоны в премиальном стиле (dark + gold).
- `routes/web.php` — маршруты.
- `database/schema.sql` — нормализованная структура БД.

## Демо-админ
Создайте пользователя с ролью `admin` в БД или обновите роль существующего пользователя в таблице `users`.

> Если MySQL недоступен, приложение автоматически переключается на SQLite (`storage/blackforge.sqlite`) для демо-просмотра интерфейса.
